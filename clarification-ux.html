Clarification 左右翻页与提交前预览

按当前 Coding Terminal 的 dark 主题和按键画的画面稿。英文文案、勾选符号、底栏提示和「先预览再发送」都与现在的实现一致。方向键、空格、回车可以在最下面那一屏里直接试。

左右翻页

多个问题不再只能从第一题走到最后一题。左、右会换题，已经勾过的答案和高亮行都留着。这一题还没答完也可以往右看。

提交前预览

最后一次确认不会直接发给 Runtime。预览列出每一题将要发送的选项或文字。回车某一行回去改；只有回车 Send answer 才提交。多选的最后一行因此改成 Review answers。

自己按一遍

点一下终端，然后用键盘。左 / 右换题，上 / 下移动，空格打勾，回车确认。也可以点右边的键。

这一屏在做什么

按键

  1. 左右换题，不丢已选答案，高亮停在离开时的那一行。
  2. 空格只打勾。单选是 ( ) / (✓)，多选是 [ ] / [✓]。
  3. 最后一题还没答完时，向右不会打开预览。
  4. 预览里回车某一题会回去改；回车 Send answer 才提交。
  5. 预览里按左，回到刚才那一题，而不是回到高亮的那一行。
