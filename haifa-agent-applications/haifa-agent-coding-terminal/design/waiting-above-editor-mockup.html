布局（对齐现有 lowerRegions）

  • 位置：现有 Pending 区块所在位置——Editor / Prompt Box 正上方，不进入 Transcript。
  • Waiting 卡展示完整文本（可折行），不只一行 summary；过长时最多 3 行 + 省略，Edit 可看全文。
  • 动作行：Send Now 主操作；Edit 次级；Cancel 右对齐弱化。
  • 底层 statusline 仍显示 ⠋ WORKING … · esc interrupt，不被 Waiting 占用。
  • Meta 条右侧提示从 enter steer 改为 enter waiting（设计提案）。

状态与键位提案

  1. Active + Enter → 清空 Editor，创建 Waiting（本地，未调用 Steer API）
  2. Waiting + Send Now / ctrl+enter → Steer；卡变为 Sending，等模型接受
  3. Waiting + Edit / e → 就地编辑；Save 回 Waiting，不自动发送
  4. Waiting + Cancel / Esc（无 cancel-armed 时）→ 丢弃 Waiting
  5. Run 自然结束且仍有 Waiting → 作为下一条 Turn / Follow-up 发出（无需 Send Now）
  6. 保留 alt+enter 直接写持久 Follow-up Queue（可与 Waiting 并存，后续实现再定）
