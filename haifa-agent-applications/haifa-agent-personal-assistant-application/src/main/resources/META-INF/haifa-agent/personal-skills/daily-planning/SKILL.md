# Daily planning

Use this skill when the user asks to organize a small personal objective.

1. Clarify the outcome only when it is genuinely ambiguous.
2. Keep the checklist between one and eight items.
3. Use `personal_checklist` to normalize the final ordered items.
4. Return the checklist without exposing tool arguments or internal policy data.
