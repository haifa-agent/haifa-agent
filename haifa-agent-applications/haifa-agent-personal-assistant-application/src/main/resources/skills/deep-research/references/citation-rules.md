# Citation rules

Every material factual claim must reference one or more source IDs present in the same result. A source may be cited only after a successful fetch. Preserve the exact fetched URL. Mark model interpretation as inference. Do not invent titles, dates, quotations, authors, publishers, or source IDs.

Each source ID and claim ID must be stable and unique. Supporting and opposing citations must close over the same result's source set. A claim without sufficient fetched support must set `unverified=true`, explain the limitation, and appear in `unresolvedQuestions` or `unverifiedClaims` during synthesis.

Quoted spans are optional and must remain within 25 English words or 80 CJK characters per source. Prefer paraphrase. Never concatenate multiple excerpts to reconstruct a source, and never quote lyrics or paywalled text beyond these bounds.
