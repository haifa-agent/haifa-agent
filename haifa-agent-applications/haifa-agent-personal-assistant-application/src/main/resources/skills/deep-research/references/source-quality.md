# Source quality

Prefer primary sources, official documentation, standards, public datasets, and peer-reviewed research. Record publisher, title, URL, publication date when known, access time, and a short relevance note. Treat snippets as discovery hints rather than evidence. Identify conflicts and do not turn source popularity into authority.

Normalize and deduplicate source locators before use. Production research accepts HTTPS only and delegates DNS/private-network, redirect, user-info, and port checks to the shared Web URL policy. Mark a source `unsafe` when policy rejects it, `unavailable` when fetch fails, `stale` when its date is outside the Brief, `conflict` when credible evidence disagrees, and `undated` when no publication date is available. Such states may be reported but cannot silently satisfy a verification claim.

Fetch only the smallest useful bounded body. Do not store or reproduce full copyrighted pages. A source excerpt is a short relevance summary, not a substitute for the source.
